LIVEVIVAL — Brand & Website Asset Kit
======================================

Read: Livevival_Brand_Guide.pdf (full brand guide + implementation checklist)

Folders:
  /favicons     -> browser tab icon + PWA home-screen icons (favicon.ico + PNGs)
  /app-icons    -> full iOS/Android/PWA icon size set (57px-1024px)
  /social       -> Open Graph / Twitter card image + square profile image
  /logo         -> logo lockup (dark & light bg), standalone icon, app icon badge

Files:
  tokens.css        -> all brand colors, fonts, spacing as CSS variables
  site.webmanifest   -> PWA manifest (already points at /favicons icons)
  head-snippet.html  -> paste into your <head> — wires up favicons, manifest,
                        theme-color, Open Graph/Twitter tags, and Google Fonts
